? ROOT CAUSE                                                                   ?
????????????????????????????????????????????????????????????????????????????????

  C Runtime Library (CRT) Mismatch:
  
  Compiler:  Uses STATIC CRT (/MTd)
  Linker:    Trying to use DYNAMIC CRT import symbols (__imp__)
  
  The "__imp__" prefix means "import from DLL"
  ? Not available when using static CRT linking!

????????????????????????????????????????????????????????????????????????????????
? THE FIX                                                                      ?
????????????????????????????????????????????????????????????????????????????????

  File:    source/Tools/ActorTools/ActBuild.vcxproj
  Change:  Added to Link section (Debug & Release):
  
  <IgnoreSpecificDefaultLibraries>msvcrt.lib</IgnoreSpecificDefaultLibraries>
  
  This forces the linker to use STATIC CRT and ignore dynamic imports.
  
  Backup:  ActBuild.vcxproj.backup.runtime

? TECHNICAL DETAILS                                                            ?
????????????????????????????????????????????????????????????????????????????????

  Static CRT (/MT, /MTd):
    - CRT code linked INTO your EXE
    - Functions in LIBCMT.lib / LIBCMTD.lib
    - Self-contained, no DLL needed
    - No __imp__ prefix
  
  Dynamic CRT (/MD, /MDd):
    - CRT code in MSVCRT.dll
    - Import definitions in MSVCRT.lib
    - Smaller EXE, needs DLL at runtime
    - Uses __imp__ prefix for imports
  
  The Fix:
    Project uses /MTd (static) but linker found MSVCRT.lib (dynamic)
    ? Ignore MSVCRT.lib ? Forces LIBCMTD.lib (static)
    ? All symbols resolve! ?
