? ERROR 3: LNK2019 - Unresolved CRT Symbols (12 Errors)                       ?
????????????????????????????????????????????????????????????????????????????????

  Error Message:
    LNK2019: unresolved external symbol __imp__[function]

  Missing Symbols (12 total):
    __imp__strtok, __imp___access, __imp__fseek, __imp__fwrite,
    __imp__fread, __imp___findclose, __imp___findfirst64i32,
    __imp___findnext64i32, __imp___mkdir, __imp__strtod,
    __imp__system, __except_handler4_common

  Problem:
    C RUNTIME LIBRARY (CRT) MISMATCH
    
    Compiler setting:  Static CRT (/MTd)
    Linker behavior:   Looking for dynamic CRT imports (__imp__)
    
    The __imp__ prefix = "import from DLL"
    ? Not available in static CRT!

  Solution:
    Force linker to ignore dynamic CRT library
    
  Modified File:
    source/Tools/ActorTools/ActBuild.vcxproj
    
  Change:
    <IgnoreSpecificDefaultLibraries>msvcrt.lib</IgnoreSpecificDefaultLibraries>
    
  What This Does:
    - Ignores dynamic CRT import library (MSVCRT.lib)
    - Forces use of static CRT (LIBCMTD.lib)
    - Resolves all __imp__ symbol errors
    
  Technical:
    Static CRT (/MT):  Functions in LIBCMT.lib, no __imp__
    Dynamic CRT (/MD): Functions imported from MSVCRT.dll via __imp__
    
    Project uses /MT but linker found MSVCRT.lib
    ? Ignore MSVCRT.lib ? Use LIBCMT.lib ? Symbols resolve!

  Backup: ActBuild.vcxproj.backup.runtime
